How to get more green

UNVERIFIED runtimes are partial backups missing package.json, so they can't build or run. Restore each project's full tree (with manifest, lockfile, and tests), declare a verifyCmd in the Evidence Agent's runtime list, and re-run scripts/agent/build-runtime-evidence-gallery.mjs — anything whose tests actually pass will flip to VERIFIED with its own video.
